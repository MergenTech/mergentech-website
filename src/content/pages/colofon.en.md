## Technology

This website is built with [Astro](https://astro.build) and consists of static pages. There is no database and there are no cookies. The source code is public on [GitHub](https://github.com/MergenTech/mergentech-website).

## Fonts

- **JetBrains Mono** for headings and accents (SIL Open Font License).
- **Atkinson Hyperlegible Next** for body text (SIL Open Font License). This typeface was designed by the Braille Institute, with letters that are extra easy to tell apart.

## Accessibility

We want everyone to be able to use this website. That is why we build to WCAG 2.2, level AA. Animations follow your device setting. Use the pause button at the top to switch them off yourself.

Still running into something? Send us an email and we will fix it.
